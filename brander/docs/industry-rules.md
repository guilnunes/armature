## Health

### Health and care (health)

- Aim for WCAG 2.2 AAA wherever it is achievable, not only for contrast.
- Status (normal, attention, critical) is always shown with an icon and words, never color alone, and status colors are never replaced by wallpaper colors.
- Clinical values always carry their unit and reference range.
- Destructive and irreversible actions (deleting records, sending prescriptions) require explicit confirmation that names what will happen.
- Plan for offline and poor connectivity: show sync state and never lose input.
- Plain language at about an 8th grade reading level for patient facing text.

Effective rules: text contrast 7:1, UI contrast 3:1, smallest text 16px, touch targets 48px, dynamic color never or opt-in.

## Scriptorium

### Information science and knowledge tools (information-science)

- Long reading is set for comfort: reading face, generous line height, 60 to 75 characters per line.
- Identifiers and classification codes use a monospaced face so they line up.
- Every item shows where it is filed; nothing is lost without a trace (undo, trash, history).
- The user's data can always be exported in an open format.

Effective rules: text contrast 4.5:1, UI contrast 3:1, smallest text 14px, touch targets 48px, dynamic color never or opt-in or default.
